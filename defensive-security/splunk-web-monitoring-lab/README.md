# Web Security Monitoring System using Splunk

## Overview
This project focuses on implementing a web security monitoring solution using Splunk Cloud to detect suspicious web activity, monitor HTTP errors, and identify potential brute-force or scanning attempts.

---

## Objectives
- Monitor suspicious HTTP errors (404, 500)
- Track web traffic patterns
- Detect excessive 404 requests from single IP addresses
- Configure alerts and scheduled reports
- Visualize security events using dashboards

---

## Platform Used
- Splunk Cloud

---

## Security Use Cases
### HTTP Error Monitoring
- Detection of 404 and 500 status codes
- Identification of abnormal error spikes

### Traffic Analysis
- Top source IP monitoring
- Error trend visualization
- Web activity tracking

### Threat Detection
- Detection of possible brute-force attempts
- Identification of scanning behavior
- Suspicious repeated requests analysis

- Security Dashboard Creation
- Scheduled HTTP Error Reports
